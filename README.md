# 神助攻

微信小程序。聊天卡住的时候，把那段对话发出去。其他人会随机领到一条自己还没处理的求助，接一句可以直接发出去的回复。你收到通知，能查看这些回复，并把好用的那条标成「神助攻」。

## 怎么用

底部四个入口：

- **首页**：发出「我卡住了」，或去接别人的一句。也能看到自己发出的求助和新回复。
- **助攻**：一次领一题。写出回复，或跳过。跳过和回复都算处理过，不会再抽到同一条；中途离开，再进来还是这一题。回复少的帖子更容易被抽到。
- **消息**：有人回复你，或你的回复被盖章时，会出现在这里。
- **我的**：求助、助攻、神助攻的数量，以及你接过的话。试用阶段可以「换一个身份」，在同一台手机上扮演两个人。

发帖时把对话拆成「对方 / 我」。最后一句会标成卡住的地方。帖子详情里可以复制回复，作者可以盖章或撤销，也可以收起求助，收起后不再被匹配。

一条求助可以有很多人回复。别人看不到你收到的其他回复。没领到这题的人，也打不开帖子内容。

## 本地跑起来

需要 Node.js 22。

```bash
cd server
npm install
SEED=1 npm start
```

`SEED=1` 会在空数据库里放四条示例求助。服务默认听 `http://127.0.0.1:8787`。

然后用微信开发者工具打开**仓库根目录**（不是 `miniprogram/`）。`project.config.json` 里已经关掉了域名校验。AppID 可以用测试号；当前填的是 `touristappid`。

小程序默认是试用登录：输入昵称就能进。想自己把流程走通，用一个身份发帖，再到「我的」换一个身份去助攻。

真机预览时，把 `miniprogram/utils/config.js` 里的 `apiBase` 改成电脑的局域网地址，并在开发者工具里勾选「不校验合法域名」。

## 接上微信登录和订阅消息

1. 把 `miniprogram/utils/config.js` 的 `authMode` 改成 `wechat`，`project.config.json` 的 `appid` 换成你的小程序 AppID。
2. 启动后端时带上：

```bash
WX_APPID=你的AppID \
WX_SECRET=你的AppSecret \
WX_TEMPLATE_REPLY=回复提醒模板ID \
WX_TEMPLATE_GOD=神助攻模板ID \
npm start
```

3. 两个订阅消息模板都使用这三个关键词，顺序固定：

| 关键词 | 含义 |
| --- | --- |
| thing1 | 摘要。收到回复时是求助说明，被盖章时是「你的回复被标成了神助攻」 |
| thing2 | 回复内容，最多 20 个字 |
| time3 | 时间 |

4. 把模板 ID 填进 `config.js` 的 `replyTemplateId` 和 `godTemplateId`。发帖时申请「有人回复」的订阅，送出助攻时申请「被盖成神助攻」的订阅。用户点允许一次，后端才能推一条。站内消息不依赖这个授权。

内容安全接口会在配置了微信密钥后自动调用。微信判为违规会拒绝发布；接口本身故障时不拦截，避免整站发不出帖。

服务器域名配好之后，把请求域名设成你的 API 地址。数据文件在 `server/data/app.db`，可以用 `DB_PATH` 和 `PORT` 改位置和端口。

## 目录

- `miniprogram/`：小程序页面。
- `server/`：接口。匹配、通知和神助攻的规则在 `server/test/` 里。

```bash
cd server
npm test
```
